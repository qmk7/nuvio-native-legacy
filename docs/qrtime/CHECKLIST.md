تُحدَّث مع كل تغيير. **لا يُعلَّم بند "منجز" إلا بدليل:** اختبار آلي ناجح، أو صورة من تشغيل فعلي،
أو تحقق على التلفاز.

| الرمز | المعنى |
|---|---|
| ✅ | منجز ومُختبر آليًا |
| 🟡 | موجود في الأساس ويعمل، أو جزئي، ولم يُختبر طرفيًا بعد |
| ⏳ | قيد العمل |
| ❌ | غير موجود |
| 🚫 | غير ممكن تقنيًا أو قانونيًا كما طُلب (مع البديل الموثّق) |
| 📺 | يحتاج تحققًا على LG OLED B5، ولا يُعتبر منجزًا قبله |
